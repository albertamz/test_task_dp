Test task: Django (бронювання столиків)
--------------------------------------

Репозиторій: [git](https://gitlab.com/alexsukhykh/test_task_django)

Це тестове завдання: реалізувати простий JSON API для бронювання столиків у кафе.

## Вимоги

- Python 3.11+
- pip, venv
- База даних: SQLite (вбудована, налаштовано за замовчуванням)

## Швидкий старт

1. Клонувати репозиторій та перейти в директорію проєкту
2. Створити та активувати віртуальне середовище
3. Встановити залежності
4. Застосувати міграції
5. Запустити сервер

## Моделі

- `db.Table`: `id`, `name`
- `db.Booking`: `id`, `table(FK)`, `date(DateField)`, `client_name`, `client_phone`


## Маршрути та API

Базовий префікс: `/`

- GET `/` — повертає список усіх столиків

  Приклад відповіді:
  ```json
  {
    "tables": [
      {"id": 1, "name": "Table 1"},
      {"id": 2, "name": "Table 2"}
    ]
  }
  ```

- GET `/?date=DD.MM.YYYYT HH:MM` — задумано повертати доступні столики для вказаної дати/часу у вікні ±2 години. Поки що реалізація спрощена і повертає усі столики (див. `app/views.py`).

- POST `/` — створення бронювання (задум API)

  Очікуваний JSON:
  ```json
  {
    "client_name": "Alex",
    "client_phone": "0931234567",
    "date": "29.06.2023T20:00",
    "table": 2
  }
  ```

  Поточна реалізація повертає заглушку-відповідь із цими полями (без фактичного створення) — це свідомо залишено для подальшої імплементації.



## Роадмап імплементації

- Можна вносити будь які зміни до будь яких файлів
- Реалізувати пошук доступних столиків у вікні ±2 години
- Реалізувати створення бронювання (валідація, конфлікти, 201 Created)
- Додати прості тести та приклади `curl`

## Приклади запитів

```bash
# Отримати всі столики
curl -s http://127.0.0.1:8000/

# Перевірити доступність (поточна реалізація — заглушка)
curl -s "http://127.0.0.1:8000/?date=01.07.2023T20:00"

# Створити бронювання (поточна реалізація — заглушка)
curl -s -X POST http://127.0.0.1:8000/ \
  -H "Content-Type: application/json" \
  -d '{"client_name":"Alex","client_phone":"0931234567","date":"29.06.2023T20:00","table":2}'
```
